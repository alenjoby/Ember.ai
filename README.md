# Ember AI

An interactive, compassionate spatial workspace for anonymous thought sharing, emotional support, and creative expression.

## Features

- **Spatial Mind Space**: Interactive canvas for thoughts and responses.
- **Multi-Modal Expressive Tools**: Text notes, audio recordings, canvas drawings, and stickers.
- **SafeSpace Guard**: Client-side sentiment analysis & compassionate content boundaries.
- **AI Companion**: Warm, empathetic responses and acoustic guidance powered by Supabase edge routines.

## Getting Started

### Prerequisites

- Node.js 18+
- npm / pnpm / yarn

### Installation & Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
